# TECHFEST 3D — IIT Bombay

A 3D interactive Techfest concept website built with:
- Three.js for the particle-space environments
- GSAP + ScrollTrigger for scroll choreography
- HTML/CSS for the UI, typography and generated visual objects
- No external 3D model assets

## Run

Open `techfest.html` in a modern browser.

For the most reliable local development experience, use VS Code with Live Server or another static local server.

## Important

The countdown date in `script.js` is a placeholder design date and must be replaced with the official Techfest 2026 festival date when confirmed.
