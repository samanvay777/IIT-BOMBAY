# DEPTH — Scroll Experience

A completely new interactive scrolling concept focused on visual depth rather than a conventional landing-page layout.

## Features
- Multiple independent parallax layers
- Background / midground / foreground motion at different speeds
- GSAP ScrollTrigger choreography
- Perspective tunnel
- Interactive mouse parallax
- Hover-reactive cursor
- Rotating depth lab
- Large typography transitions
- Responsive mobile layout
- Reduced-motion support
- No 3D model assets required

## Run
Open `index.html` (named `techfest.html` here) in a modern browser, preferably through VS Code Live Server.
